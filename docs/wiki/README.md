# Nhuu-chat Wiki

Nhuu-chat là MVP inbox Telegram và RAG độc lập. Xem README gốc để biết cách chạy, các module đã hoàn thành, giới hạn môi trường và kế hoạch trước production.

Trạng thái hiện tại: backend/API, Telegram webhook, RAG adapter, Bot Pause/retry và inbox React tối thiểu đã có. Cần xác minh Docker Mongo/Redis, E2E deploy thật, vector store production và load test trước khi phát hành chính thức.
